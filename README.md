## Selected Projects

### [T4bl - Domain-Specific Language](https://github.com/PhilipHellerup/T4BL-Domain-Specific-Language-for-Data-Transformation)
A domain-specific programming language for readable and reproducible CSV data transformation, implemented as a Java tree-walking interpreter.

`Java` · `JavaCC` · `DSL` · `Parsing` · `AST` · `Interpreters`

### [Bicycle Repair Management System](https://github.com/PhilipHellerup/Bicycle-Repair-Management-System-for-Performsport)
A full-stack repair management system developed in collaboration with Performsport to digitalize bicycle repair scheduling and workflow management.

`Java` · `Spring Boot` · `PostgreSQL` · `Thymeleaf` · `JPA` · `Docker`

### [Browser-Based Grid Computing Platform](https://github.com/PhilipHellerup/Browser-Based-Grid-Computing-Platform)
A distributed browser-based computing platform that uses volunteer clients to perform SHA-512 password auditing.

`JavaScript` · `Node.js` · `Express.js` · `WebSockets` · `Web Workers` · `MySQL`

### [Drone Route Optimization](https://github.com/PhilipHellerup/Drone-Route-Optimization)
A route optimization program using Branch and Bound to solve the Traveling Salesman Problem for drone-based medical deliveries.

`C` · `CMake` · `Branch and Bound` · `Graph Theory` · `TSP`
